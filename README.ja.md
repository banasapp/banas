# Banas

**言語：** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [ภาษาไทย](README.th.md) · [Tiếng Việt](README.vi.md)

ローカルライブラリ管理とメタデータ収集ツールです。ローカル動画をスキャンし、品番でカバーとタイトルを補完し、Emby 風またはカスタムテンプレートでフォルダを整理します。

コンテンツソース・ダウンロードソースなどサイト設定は利用者自身が追加できます。Banas は第三者サイトやオンラインコンテンツをホスト・運営しません。

UI 言語：English、简体中文、繁體中文、日本語、한국어、ภาษาไทย、Tiếng Việt。

Jasna（動画デコード）、Transub（字幕）、Transub Player と連携します。パスは「設定 → ツール」または「設定 → ライブ」で指定します。

**ドキュメント：** [コンテンツ／ダウンロードソースの追加方法](HOW-TO-ADD-SOURCES.ja.md) · [ソースのエクスポート／インポート](HOW-TO-IMPORT-EXPORT-SOURCES.ja.md)

## 機能一覧

| モジュール | 用途 |
| --- | --- |
| **ライブラリ** | ローカルフォルダをスキャンし、カバー / タイトル / 字幕を補完、テンプレートで整理 |
| **カバー** | 品番でカバーを検索・保存（組み込みルールあり、編集可） |
| **フィルター** | 女優・レーベル・メーカー・ジャンルのカタログ、検索とランダム閲覧 |
| **コンテンツソース** | 独自サイト一覧。HTML / JSON / ブラウザ描画、視覚的フィールド選択 — [手順](HOW-TO-ADD-SOURCES.ja.md) |
| **ダウンロードソース** | 品番またはキーワードでリソースを検索し、コピーまたは開く — [手順](HOW-TO-ADD-SOURCES.ja.md) |
| **ウォッチ** | コンテンツソースの新規をポーリング、または指定品番のダウンロード有無を監視 |
| **ライブ** | カテゴリで配信者を閲覧、お気に入りと最近視聴。内蔵ページまたは Transub Player |
| **ショートカットとジョブ** | よく使うソースを固定。バックグラウンドジョブの進捗確認と再試行 |
| **プライバシー** | トレイに隠す、起動パスワード、ボスキーで一発非表示 |

## 使い方

左のアイコンレールでモジュールを切り替え、右隣のサイドバーで一覧と管理、メイン領域でカバーグリッド・表・設定を表示します。サイドバータイトル横の歯車で管理（並べ替え・編集・削除）できます。

### ライブラリ

1. サイドバー **フォルダを追加** → フォルダ選択、表示名、カバー元（組み込みルール / 同フォルダのローカル画像）→ 保存。
2. フォルダまたは「すべてのフォルダ」→ **スキャン**。検索や「カバーなし」などの絞り込みが可能。
3. ツールバーで **作品別 / 女優別**、一括で **カバー・タイトル・字幕の補完**、**整理**、**Jasna デコード**。
4. カバーをクリックで詳細（再生、フォルダを開く、編集）。右クリックでタイトル / カバー検索、整理、女優フォルダへ移動。

関連設定：**タイトルと女優**、**動画の整理**（パス雛形、`movie.nfo` / `poster.jpg`）、**ツール**（Jasna、Transub）。

### カバー（品番検索）

1. **ショートカット** 下部に品番を 1 行以上入力（またはメイン領域にファイルをドロップ。ファイル名を品番として使用）→ **検索**。
2. 結果グリッドでプレビュー・画像元の切替。右クリックでカバーを別名保存。
3. ルールは **設定 → 動画カバー** で追加・診断。

### フィルター

1. サイドバー **女優 / レーベル / メーカー / ジャンル** → ポップアップで検索して項目を選択。
2. メインに関連動画。サイドバー **更新** でカタログパックを更新。
3. **管理** で追加・編集・削除・インポート / エクスポート。データは `catalog.banascat`。

### コンテンツソース

1. **追加** → サイト URL → **スマート解析** または **視覚選択**（項目・品番・カバー・ページ送りなど）→ テスト → 保存。グループ可。
2. ソースを開く：カテゴリ切替、サイト内検索、カバー壁のページ送り。
3. カバーは再生（ローカル優先、なければ解析後 Transub Player）、ダウンロード検索、リソースウォッチ。メニューで集約ウォッチやショートカット追加。
4. サイドバーの暗号化パック **インポート / エクスポート** で複数 PC 同期。

詳細：[コンテンツ／ダウンロードソースの追加方法](HOW-TO-ADD-SOURCES.ja.md)。インポート／エクスポート：[ソースのエクスポート／インポート](HOW-TO-IMPORT-EXPORT-SOURCES.ja.md)。

### ダウンロードソース

1. **ダウンロードソースを追加** → 検索 URL（キーワード用プレースホルダ）と一覧フィールドを設定 → 保存。
2. ソースを開き品番を入力 → **リソース検索** → 表で詳細・マグネットコピー・ダウンロード開始。
3. ショートカットに追加可能。インポート / エクスポート同様。リソースウォッチの既定ソースは **設定 → ウォッチ**。

詳細：[コンテンツ／ダウンロードソースの追加方法](HOW-TO-ADD-SOURCES.ja.md)。インポート／エクスポート：[ソースのエクスポート／インポート](HOW-TO-IMPORT-EXPORT-SOURCES.ja.md)。

### ウォッチ

1. **ウォッチを追加**：**集約**（コンテンツソースの新規品番）または **リソース**（品番のダウンロード有無）。
2. **集約ウォッチ / リソースウォッチ** で結果を確認。ツールバーで **今すぐポーリング** やクリア。
3. コンテンツソース側やカバーのベルでも切替。間隔は **設定 → ウォッチ**。

### ライブ

1. カテゴリ選択、または **お気に入り / 最近視聴**。検索で配信者を探せます。
2. ルームを開く：ツールバーまたは **設定 → ライブ** で **内蔵 Web**（操作可）か **Transub Player**（録画可・公開ルーム）。
3. ハートでお気に入り。表示カテゴリとミラーは **設定 → ライブ**。

### ショートカット

1. サイドバー **+** → よく使うコンテンツ / ダウンロードソースを選択 → 保存。ワンクリックで閲覧または検索。
2. 下部の **品番検索** で直接カバー検索。
3. **設定 → 一般 → 起動時のページ** でメイン領域の初期モジュールを指定（レールはショートカットのまま可）。

### ジョブ

左レール **ジョブ** でバックグラウンドキュー（スキャン、カバー取得、ウォッチポーリング、整理、デコードなど）を表示。進捗確認、**再試行** / **キャンセル**、完了済みのクリア。

### プライバシーとツール

- **設定 → プライバシーとセキュリティ**：閉じる / 最小化でトレイへ、起動パスワード、ボスキー。
- **設定 → ツール**：Jasna、Transub、Transub Player のパス。左レールのツールメニューからも起動可。
- **設定 → バックアップ**：データベースのバックアップ / 復元、設定とソースパックのエクスポート / インポート（パスワードとライセンスキーは含まない）。

## データ

動画インデックス・設定・フィルターカタログはすべて本機に保存され、アップロードされません。

```
ライブラリと設定：<Banas.exe のあるフォルダ>/data/javgt.sqlite
フィルターカタログ：<Banas.exe のあるフォルダ>/data/catalog.banascat
```

バックアップや移行時は `data` フォルダ全体をコピーしてください。

## ライセンス

初回は 3 日間フル機能トライアル。終了後もローカルライブラリのスキャン・閲覧・整理は可能。オンライン補完、一括整理、コンテンツソース、ダウンロードソース、ウォッチなどは Pro が必要です。

UniFans で購入後、アクティベーションコードの発行を待ち、「設定 → ライセンス」に貼り付けます。コードは 1 台の PC に紐づき、付け替え間隔は 30 日。期間は 1 年・2 年・永久から選択。
