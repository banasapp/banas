# Banas

**언어:** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [ภาษาไทย](README.th.md) · [Tiếng Việt](README.vi.md)

로컬 라이브러리 관리 및 메타데이터 스크래핑 도구입니다. 로컬 영상을 스캔하고, 품번으로 커버·제목을 채우며, Emby 스타일 또는 사용자 지정 템플릿으로 폴더를 정리합니다.

콘텐츠 소스·다운로드 소스 등 사이트 설정은 사용자가 직접 추가합니다. Banas는 타사 웹사이트나 온라인 콘텐츠를 호스팅·운영하지 않습니다.

UI 언어: English, 简体中文, 繁體中文, 日本語, 한국어, ภาษาไทย, Tiếng Việt.

Jasna(영상 디코드), Transub(자막), Transub Player와 연동됩니다. 경로는 **설정 → 도구** 또는 **설정 → 라이브**에서 지정합니다.

## 사용 안내

왼쪽 아이콘 레일로 모듈을 전환하고, 옆 사이드바에서 목록·관리, 메인 영역에서 커버 격자·표·설정을 봅니다. 사이드바 제목 옆 톱니로 관리(정렬·편집·삭제)합니다.

### 라이브러리

1. 사이드바 **폴더 추가** → 폴더 선택, 이름, 커버 출처(내장 규칙 / 같은 폴더 로컬 이미지) → 저장.
2. 폴더 또는 **모든 폴더** → **스캔**. 검색 및 「커버 없음」 등 필터 사용.
3. 도구 모음에서 **작품별 / 배우별**, 일괄 **커버·제목·자막 채우기**, **정리**, **Jasna 디코드**.
4. 커버 클릭으로 상세(재생, 폴더 열기, 편집). 우클릭으로 제목/커버 조회, 정리, 배우 폴더로 이동.

관련 설정: **제목 및 배우**, **영상 정리**(경로 템플릿, `movie.nfo` / `poster.jpg`), **도구**(Jasna, Transub).

### 커버(품번 조회)

1. **바로가기** 하단에 품번을 한 줄 이상 입력(또는 메인에 파일 드롭, 파일명을 품번으로 사용) → **찾기**.
2. 결과 격자에서 미리보기·이미지 소스 전환. 우클릭으로 커버 다른 이름으로 저장.
3. 규칙은 **설정 → 영상 커버**에서 추가·진단.

### 필터

1. 사이드바 **배우 / 레이블 / 제작사 / 장르** → 팝업에서 검색 후 항목 선택.
2. 메인에 관련 영상. 사이드바 **새로고침**으로 카탈로그 팩 갱신.
3. **관리**에서 추가·편집·삭제·가져오기/내보내기. 데이터는 `catalog.banascat`.

### 콘텐츠 소스

1. **추가** → 사이트 URL → **스마트 파싱** 또는 **시각 선택**(항목·품번·커버·페이지 등) → 테스트 → 저장. 그룹 가능.
2. 소스 열기: 카테고리 전환, 사이트 내 검색, 커버 벽 페이지 이동.
3. 커버 재생(로컬 우선, 없으면 파싱 후 Transub Player), 다운로드 조회, 리소스 감시. 메뉴에서 집계 감시·바로가기 추가.
4. 사이드바 암호화 팩 **가져오기 / 내보내기**로 여러 PC 동기화.

### 다운로드 소스

1. **다운로드 소스 추가** → 검색 URL(키워드 자리 표시자)과 목록 필드 설정 → 저장.
2. 소스 열고 품번 입력 → **리소스 찾기** → 표에서 상세·마그넷 복사·다운로드.
3. 바로가기 가능. 가져오기/내보내기 동일. 리소스 감시 기본 소스는 **설정 → 감시**.

### 감시

1. **감시 추가**: **집계**(콘텐츠 소스의 새 품번) 또는 **리소스**(품번 다운로드 여부).
2. **집계 감시 / 리소스 감시**에서 결과 확인. 도구 모음에서 **지금 폴링**·비우기.
3. 콘텐츠 소스 사이드바나 커버의 종으로도 전환. 간격은 **설정 → 감시**.

### 라이브

1. 카테고리 선택, 또는 **즐겨찾기 / 최근**. 검색으로 스트리머 찾기.
2. 방 열기: 도구 모음 또는 **설정 → 라이브**에서 **내장 웹**(상호작용) 또는 **Transub Player**(녹화, 공개 방).
3. 하트로 즐겨찾기. 카테고리·미러는 **설정 → 라이브**.

### 바로가기

1. 사이드바 **+** → 자주 쓰는 콘텐츠/다운로드 소스 선택 → 저장. 한 번에 탐색 또는 조회.
2. 하단 **품번 조회**로 바로 커버 검색.
3. **설정 → 일반 → 시작 페이지**로 메인 초기 모듈 지정(레일은 바로가기 유지 가능).

### 작업

왼쪽 레일 **작업**에서 백그라운드 큐(스캔, 커버 다운로드, 감시 폴링, 정리, 디코드 등) 확인. 진행률, **재시도** / **취소**, 완료 항목 지우기.

### 개인정보 및 도구

- **설정 → 개인정보 및 보안**: 닫기/최소화 시 트레이, 시작 암호, 보스 키.
- **설정 → 도구**: Jasna, Transub, Transub Player 경로. 왼쪽 도구 메뉴에서도 실행 가능.
- **설정 → 백업**: DB 백업/복원, 설정·소스 팩 내보내기/가져오기(암호·라이선스 키 제외).

## 데이터

영상 인덱스·설정·필터 카탈로그는 모두 기기에 저장되며 업로드되지 않습니다.

```
라이브러리 및 설정: <Banas.exe 폴더>/data/javgt.sqlite
필터 카탈로그:     <Banas.exe 폴더>/data/catalog.banascat
```

백업·이전 시 `data` 폴더 전체를 복사하면 됩니다.

## 라이선스

최초 3일 전체 기능 체험. 종료 후에도 로컬 라이브러리 스캔·탐색·정리는 가능합니다. 온라인 채우기, 일괄 정리, 콘텐츠 소스, 다운로드 소스, 감시 등은 Pro가 필요합니다.

UniFans에서 구매 후 활성화 코드를 받아 **설정 → 라이선스**에 붙여넣습니다. 코드는 PC 1대에 묶이며 재바인딩 간격은 30일. 기간: 1년, 2년, 영구.

---

## 안내

설정·라이브러리·라이선스는 주로 기기에 저장됩니다. 온라인 시 라이선스 확인을 위해 제한된 기술 정보(기기 ID 등)가 전송될 수 있습니다.

사용자가 추가한 소스(필터 카탈로그, 콘텐츠 소스, 다운로드 소스 등), 프록시·타사 사이트의 가용성·법령 준수는 사용자 책임입니다.
