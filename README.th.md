# Banas

**ภาษา:** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [ภาษาไทย](README.th.md) · [Tiếng Việt](README.vi.md)

เครื่องมือจัดการคลังวิดีโอในเครื่องและดึงข้อมูลเมตา: สแกนไฟล์วิดีโอในเครื่อง เติมปกและชื่อเรื่องตามรหัสผลงาน และจัดโฟลเดอร์ด้วยเทมเพลตแบบ Emby หรือแบบกำหนดเอง

เพิ่มแหล่งเนื้อหา แหล่งดาวน์โหลด และการตั้งค่าไซต์ได้เอง Banas ไม่โฮสต์และไม่ดำเนินเว็บไซต์หรือเนื้อหาออนไลน์ของบุคคลที่สาม

ภาษา UI: English, 简体中文, 繁體中文, 日本語, 한국어, ภาษาไทย, Tiếng Việt

ทำงานร่วมกับ Jasna (ถอดรหัสวิดีโอ), Transub (คำบรรยาย) และ Transub Player ตั้งค่าเส้นทางที่ **การตั้งค่า → เครื่องมือ** หรือ **การตั้งค่า → ไลฟ์**

**เอกสาร:** [วิธีเพิ่มแหล่งเนื้อหาและแหล่งดาวน์โหลด](HOW-TO-ADD-SOURCES.th.md)

## วิธีใช้

แถบไอคอนซ้ายสลับโมดูล แถบข้างรองแสดงรายการและจัดการ พื้นที่หลักแสดงตารางปก ตาราง หรือแบบฟอร์มตั้งค่า ใช้เฟืองข้างชื่อแถบข้างเพื่อจัดการ (เรียง แก้ไข ลบ)

### คลัง

1. แถบข้าง **เพิ่มโฟลเดอร์** → เลือกโฟลเดอร์ ตั้งชื่อ เลือกแหล่งปก (กฎในตัว / รูปในโฟลเดอร์เดียวกัน) → บันทึก
2. เลือกโฟลเดอร์หรือ **ทุกโฟลเดอร์** → **สแกน** ใช้ค้นหาและตัวกรอง เช่น ไม่มีปก
3. แถบเครื่องมือ: สลับ **ตามเรื่อง / ตามนักแสดง** เติม **ปก ชื่อเรื่อง คำบรรยาย** เป็นชุด รวมถึง **จัดเก็บ** และ **ถอดรหัส Jasna**
4. คลิกปกเพื่อรายละเอียด (เล่น เปิดโฟลเดอร์ แก้ไข) คลิกขวาเพื่อค้นชื่อ/ปก จัดเก็บ หรือย้ายไปโฟลเดอร์นักแสดง

การตั้งค่าที่เกี่ยวข้อง: **ชื่อเรื่องและนักแสดง**, **จัดเก็บวิดีโอ** (เทมเพลตพาธ, `movie.nfo` / `poster.jpg`), **เครื่องมือ** (Jasna, Transub)

### ปก (ค้นหารหัส)

1. ที่ด้านล่างของ **ทางลัด** พิมพ์รหัสหนึ่งบรรทัดหรือหลายบรรทัด (หรือลากไฟล์มาที่พื้นที่หลัก ใช้ชื่อไฟล์เป็นรหัส) → **ค้นหา**
2. ในตารางผลลัพธ์ คลิกเพื่อดูตัวอย่างและสลับแหล่งรูป คลิกขวาเพื่อบันทึกปก
3. แก้ไขและวินิจฉัยกฎที่ **การตั้งค่า → ปกวิดีโอ**

### กรอง

1. แถบข้าง **นักแสดง / ป้าย / ผู้ผลิต / ประเภท** → ค้นหาและเลือกรายการในป๊อปอัป
2. พื้นที่หลักแสดงวิดีโอที่เกี่ยวข้อง แถบข้าง **รีเฟรช** อัปเดตแพ็กแคตตาล็อก
3. **จัดการ** เพื่อเพิ่ม แก้ไข ลบ นำเข้า/ส่งออก ข้อมูลอยู่ใน `catalog.banascat`

### แหล่งเนื้อหา

1. **เพิ่ม** → ใส่ URL ไซต์ → **แยกวิเคราะห์อัจฉริยะ** หรือ **เลือกแบบมองเห็น** (รายการ รหัส ปก หน้า ฯลฯ) → ทดสอบ → บันทึก จัดกลุ่มได้
2. เปิดแหล่ง: สลับคอลัมน์ ค้นในไซต์ พลิกหน้าผนังปก
3. ปกเล่นได้ (ในเครื่องก่อน ไม่เช่นนั้นแยกแล้วใช้ Transub Player) ค้นดาวน์โหลด หรือเข้าร่วมติดตามทรัพยากร เมนูแหล่งเปิดติดตามรวมหรือเพิ่มทางลัดได้
4. แถบข้าง **นำเข้า / ส่งออก** แพ็กเข้ารหัสเพื่อซิงก์หลายเครื่อง

รายละเอียด: [วิธีเพิ่มแหล่งเนื้อหาและแหล่งดาวน์โหลด](HOW-TO-ADD-SOURCES.th.md)

### แหล่งดาวน์โหลด

1. **เพิ่มแหล่งดาวน์โหลด** → ตั้ง URL ค้นหา (มีตัวแทนคำสำคัญ) และฟิลด์รายการ → บันทึก
2. เปิดแหล่ง พิมพ์รหัส → **ค้นหาทรัพยากร** → เปิดรายละเอียด คัดลอกแมกเน็ต หรือเริ่มดาวน์โหลดในตาราง
3. ปักหมุดทางลัดได้ นำเข้า/ส่งออกเหมือนกัน แหล่งดาวน์โหลดเริ่มต้นของการติดตามทรัพยากรอยู่ที่ **การตั้งค่า → ติดตาม**

รายละเอียด: [วิธีเพิ่มแหล่งเนื้อหาและแหล่งดาวน์โหลด](HOW-TO-ADD-SOURCES.th.md)

### ติดตาม

1. **เพิ่มการติดตาม**: **รวม** (เลือกแหล่งเนื้อหาเพื่อรหัสใหม่) หรือ **ทรัพยากร** (ใส่รหัสเพื่อดูว่ามีดาวน์โหลด)
2. ดูผลใน **ติดตามรวม / ติดตามทรัพยากร** แถบเครื่องมือ **โพลทันที** หรือล้าง
3. กระดิ่งที่แถบแหล่งเนื้อหาหรือปกก็สลับได้ ช่วงเวลาอยู่ที่ **การตั้งค่า → ติดตาม**

### ไลฟ์

1. เลือกหมวด หรือเปิด **รายการโปรด / ล่าสุด** ค้นหาสตรีมเมอร์ได้
2. เปิดห้อง: เลือก **เว็บในตัว** (โต้ตอบได้) หรือ **Transub Player** (บันทึกได้ ห้องสาธารณะ) จากแถบบนหรือ **การตั้งค่า → ไลฟ์**
3. หัวใจเพื่อรายการโปรด การมองเห็นหมวดและมิเรอร์ไลฟ์อยู่ที่ **การตั้งค่า → ไลฟ์**

### ทางลัด

1. แถบข้าง **+** → เลือกแหล่งเนื้อหาหรือดาวน์โหลดที่ใช้บ่อย → บันทึก คลิกเดียวเปิดการเรียกดูหรือค้นหา
2. **ค้นหารหัส** ด้านล่างค้นปกได้ทันที
3. **การตั้งค่า → ทั่วไป → หน้าเริ่มต้น** กำหนดโมดูลที่เปิดในพื้นที่หลัก (แถบซ้ายอยู่ที่ทางลัดได้)

### งาน

**งาน** บนแถบซ้ายแสดงคิวพื้นหลัง (สแกน ดาวน์โหลดปก โพลติดตาม จัดเก็บ ถอดรหัส ฯลฯ) ดูความคืบหน้า **ลองใหม่** หรือ **ยกเลิก** และล้างรายการที่เสร็จแล้ว

### ความเป็นส่วนตัวและเครื่องมือ

- **การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย**: ซ่อนถาดเมื่อปิด/ย่อ รหัสผ่านตอนเริ่ม ปุ่มบอส
- **การตั้งค่า → เครื่องมือ**: เส้นทาง Jasna, Transub, Transub Player เมนูเครื่องมือแถบซ้ายก็เปิดได้
- **การตั้งค่า → สำรอง**: สำรอง/กู้คืนฐานข้อมูล หรือส่งออก/นำเข้าการตั้งค่าและแพ็กแหล่ง (ไม่รวมรหัสผ่านและคีย์ใบอนุญาต)

## ข้อมูล

ดัชนีวิดีโอ การตั้งค่า และแคตตาล็อกตัวกรองเก็บในเครื่อง ไม่อัปโหลด

```
คลังและการตั้งค่า: <โฟลเดอร์ของ Banas.exe>/data/javgt.sqlite
แคตตาล็อกตัวกรอง:  <โฟลเดอร์ของ Banas.exe>/data/catalog.banascat
```

สำรองหรือย้ายแอป ให้คัดลอกทั้งโฟลเดอร์ `data`

## ใบอนุญาต

ทดลองใช้เต็มรูปแบบ 3 วันครั้งแรก หลังหมดแล้วยังสแกน เรียกดู และจัดคลังในเครื่องได้ การเติมออนไลน์ จัดชุด แหล่งเนื้อหา แหล่งดาวน์โหลด และการติดตามต้องใช้ Pro

ซื้อที่ UniFans แล้วรอรหัสเปิดใช้ วางที่ **การตั้งค่า → ใบอนุญาต** แต่ละรหัสผูกกับคอมพิวเตอร์หนึ่งเครื่อง ช่วงเปลี่ยนผูก 30 วัน เลือกระยะ: หนึ่งปี สองปี หรือตลอดชีพ

## หมายเหตุ

การตั้งค่า คลัง และใบอนุญาตเก็บในเครื่องเป็นหลัก เมื่อออนไลน์อาจส่งข้อมูลเทคนิคจำกัด (เช่น รหัสอุปกรณ์) เพื่อตรวจใบอนุญาต

ความพร้อมใช้งานและการปฏิบัติตามกฎหมายของแหล่งที่ผู้ใช้เพิ่มเอง (รวมแคตตาล็อกตัวกรอง แหล่งเนื้อหา แหล่งดาวน์โหลด) พร็อกซี และไซต์บุคคลที่สาม เป็นความรับผิดชอบของผู้ใช้
