# Banas

**語言：** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [ภาษาไทย](README.th.md) · [Tiếng Việt](README.vi.md)

本地片庫管理與資訊刮削工具：掃描本地影片、依番號補封面與片名、依規則整理目錄（含 Emby 風格與自訂範本）。

可自行新增內容源、下載源等站點設定。Banas 不託管、不營運任何第三方網站或線上內容。

介面語言：English、简体中文、繁體中文、日本語、한국어、ภาษาไทย、Tiếng Việt。

深度配合 Jasna 影片解碼、Transub 字幕產生與 Transub Player；路徑在「設定 → 工具」或「設定 → 直播」中指定。

## 功能一覽

| 模組 | 用途 |
| --- | --- |
| **本地庫** | 掃描本地目錄，補封面 / 片名 / 字幕，依範本歸檔 |
| **封面** | 依番號查找並儲存封面（內建多套規則，可自行增改） |
| **篩選** | 演員、廠牌、製作商與分類目錄，搜尋與隨機瀏覽 |
| **內容源** | 自訂站點列表，HTML / JSON / 瀏覽器渲染，視覺化點選欄位 |
| **下載源** | 依番號或關鍵字查找資源，複製或開啟結果 |
| **監聽** | 輪詢內容源新增，或輪詢指定番號是否出現可下載資源 |
| **直播** | 依分類瀏覽主播，收藏與最近觀看；內建頁或 Transub Player |
| **捷徑與任務** | 常用源釘到捷徑；背景任務查看進度並重試 |
| **隱私** | 系統匣隱藏、啟動密碼、老闆鍵一鍵隱藏 |

## 功能指引

左側為圖示軌（切換模組），其右為二級側欄（目前模組的列表與管理），主區展示封面牆、表格或設定表單。側欄標題旁的齒輪可進入管理（排序、編輯、刪除）。

### 本地庫

1. 側欄 **新增目錄** → 選擇資料夾、填寫名稱、選擇封面來源（內建規則 / 同目錄本地圖）→ 儲存。
2. 點目錄或「所有目錄」→ **掃描**；可用搜尋與「缺封面」等篩選。
3. 工具列可切換 **依影片 / 依演員**，批次 **補齊封面、片名、字幕**，以及 **歸檔**、**Jasna 解碼**。
4. 點封面開啟詳情（播放、開啟資料夾、編輯）；右鍵可查片名 / 封面、歸檔或移動至演員目錄。

相關設定：**片名和演員**、**影片歸檔**（目錄範本、`movie.nfo` / `poster.jpg`）、**工具**（Jasna、Transub）。

### 封面（番號查找）

1. 在 **捷徑** 底部輸入一行或多行番號（或把檔案拖入主區，以檔名為番號）→ **查找**。
2. 結果網格點封面可預覽、切換圖源；右鍵可將封面另存新檔。
3. 規則在 **設定 → 影片封面** 中增改與診斷。

### 篩選

1. 側欄點 **演員庫 / 廠牌庫 / 製作商庫 / 影片分類** → 在彈出目錄中搜尋並選條目。
2. 主區顯示關聯影片網格；側欄 **重新整理** 可更新篩選庫。
3. **管理** 中可增刪改條目、匯入匯出；資料保存在 `catalog.banascat`。

### 內容源

1. **新增** → 輸入站點 URL → **自動解析** 或 **視覺化點選**（條目、番號、封面、翻頁等）→ 測試 → 儲存；可分組。
2. 點源進入主區：欄目切換、站內搜尋、翻頁瀏覽封面牆。
3. 封面可播放（本地優先，否則解析後用 Transub Player）、查下載、加入資源監聽；源選單可開聚合監聽或加入捷徑。
4. 側欄支援加密包 **匯入 / 匯出**，便於多機同步。

### 下載源

1. **新增下載源** → 設定查找位址（含關鍵字佔位）與列表欄位 → 儲存。
2. 點源後在主區輸入番號 → **查找資源** → 在表格中開啟詳情、複製磁力連結或開啟下載。
3. 可加入捷徑；側欄同樣支援匯入 / 匯出。資源監聽預設使用的下載源在 **設定 → 監聽** 中指定。

### 監聽

1. **新增監聽**：**聚合**（勾選內容源，盯站點新番號）或 **資源**（輸入番號，盯下載源是否出現資源）。
2. 在 **聚合監聽 / 資源監聽** 子頁查看結果；工具列可 **立即輪詢**、清空。
3. 內容源側欄或封面上的鈴鐺也可開關監聽。輪詢間隔等在 **設定 → 監聽**。

### 直播

1. 側欄選分類，或開啟 **我喜歡的主播 / 最近觀看**；可用搜尋找主播。
2. 點房間播放：模式在頂欄或 **設定 → 直播** 中選 **內建網頁**（可互動）或 **Transub Player**（支援錄製，公開房）。
3. 卡片愛心收藏；分類可見性與直播源鏡像在 **設定 → 直播** 中設定。

### 捷徑

1. 側欄 **+** → 勾選常用內容源或下載源 → 儲存；一點即可開啟對應瀏覽或查找頁。
2. 底部 **番號查找** 可直接查封面。
3. **設定 → 一般 → 啟動後預設頁面** 可指定啟動時主區開啟的模組（側欄仍可停在捷徑）。

### 任務

左軌 **任務** 開啟背景佇列（掃描、封面下載、監聽輪詢、歸檔、解碼等），可查看進度、**重試** 或 **取消**，並清除已完成項。

### 隱私與工具

- **設定 → 隱私與安全**：關閉 / 最小化到系統匣、啟動密碼、老闆鍵一鍵隱藏視窗。
- **設定 → 工具**：指定 Jasna、Transub、Transub Player 路徑；左軌工具選單也可快捷開啟這些程式。
- **設定 → 備份**：備份 / 還原資料庫，或匯出 / 匯入設定與源資料包（不含密碼與啟用碼）。

## 資料

影片索引與設定、篩選庫均保存在本機，不上傳。

```
影片及設定：<Banas.exe 所在目錄>/data/javgt.sqlite
篩選庫：    <Banas.exe 所在目錄>/data/catalog.banascat
```

備份或遷移時，複製整個 `data` 資料夾即可。
