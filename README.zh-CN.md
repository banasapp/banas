# Banas

**语言：** [English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [ภาษาไทย](README.th.md) · [Tiếng Việt](README.vi.md)

本地片库管理与信息刮削工具：扫描本地影片、按番号补封面与片名、按规则整理目录（含 Emby 风格与自定义模板）。

可自行添加内容源、下载源等站点配置。Banas 不托管、不运营任何第三方网站或在线内容。

界面语言：English、简体中文、繁體中文、日本語、한국어、ภาษาไทย、Tiếng Việt。

深度配合 Jasna 视频解码、Transub 字幕生成与 Transub Player；路径在「设置 → 工具」或「设置 → 直播」中指定。

**文档：** [如何填写内容源与下载源](HOW-TO-ADD-SOURCES.zh-CN.md)

| **隐私** | 托盘隐藏、启动密码、老板键一键隐藏 |

## 功能指引

左侧为图标轨（切换模块），其右为二级侧栏（当前模块的列表与管理），主区展示封面墙、表格或设置表单。侧栏标题旁的齿轮可进入管理（排序、编辑、删除）。

### 本地库

1. 侧栏 **添加目录** → 选择文件夹、填写名称、选择封面来源（内置规则 / 同目录本地图）→ 保存。
2. 点目录或「所有目录」→ **扫描**；可用搜索与「缺封面」等筛选。
3. 工具栏可切换 **按影片 / 按演员**，批量 **补齐封面、片名、字幕**，以及 **归档**、**Jasna 解码**。
4. 点封面打开详情（播放、打开文件夹、编辑）；右键可查片名 / 封面、归档或移动至演员目录。

相关设置：**片名和演员**、**影片归档**（目录模板、`movie.nfo` / `poster.jpg`）、**工具**（Jasna、Transub）。

### 封面（番号查找）

1. 在 **捷径** 底部输入一行或多行番号（或把文件拖入主区，以文件名为番号）→ **查找**。
2. 结果网格点封面可预览、切换图源；右键可将封面另存为。
3. 规则在 **设置 → 影片封面** 中增改与诊断。

### 筛选

1. 侧栏点 **演员库 / 厂牌库 / 制作商库 / 影片分类** → 在弹出目录中搜索并选条目。
2. 主区显示关联影片网格；侧栏 **刷新** 可更新筛选库。
3. **管理** 中可增删改条目、导入导出；数据保存在 `catalog.banascat`。

### 内容源

1. **添加** → 输入站点 URL → **自动解析** 或 **可视化点选**（条目、番号、封面、翻页等）→ 测试 → 保存；可分组。
2. 点源进入主区：栏目切换、站内搜索、翻页浏览封面墙。
3. 封面可播放（本地优先，否则解析后用 Transub Player）、查下载、加入资源监听；源菜单可开聚合监听或加入捷径。
4. 侧栏支持加密包 **导入 / 导出**，便于多机同步。

详细填写步骤见：[如何填写内容源与下载源](HOW-TO-ADD-SOURCES.zh-CN.md)。

### 下载源

1. **添加下载源** → 配置查找地址（含关键字占位）与列表字段 → 保存。
2. 点源后在主区输入番号 → **查找资源** → 在表格中打开详情、复制磁链或打开下载。
3. 可加入捷径；侧栏同样支持导入 / 导出。资源监听默认使用的下载源在 **设置 → 监听** 中指定。

详细填写步骤见：[如何填写内容源与下载源](HOW-TO-ADD-SOURCES.zh-CN.md)。

### 监听

1. **新增监听**：**聚合**（勾选内容源，盯站点新番号）或 **资源**（输入番号，盯下载源是否出现资源）。
2. 在 **聚合监听 / 资源监听** 子页查看结果；工具栏可 **立即轮询**、清空。
3. 内容源侧栏或封面上的铃铛也可开关监听。轮询间隔等在 **设置 → 监听**。

### 直播

1. 侧栏选分类，或打开 **我喜欢的主播 / 最近观看**；可用搜索找主播。
2. 点房间播放：模式在顶栏或 **设置 → 直播** 中选 **内置网页**（可互动）或 **Transub Player**（支持录制，公开房）。
3. 卡片心形收藏；分类可见性与直播源镜像在 **设置 → 直播** 中配置。

### 捷径

1. 侧栏 **+** → 勾选常用内容源或下载源 → 保存；一点即可打开对应浏览或查找页。
2. 底部 **番号查找** 可直接查封面。
3. **设置 → 通用 → 启动后默认页面** 可指定启动时主区打开的模块（侧栏仍可停在捷径）。

### 任务

左轨 **任务** 打开后台队列（扫描、封面下载、监听轮询、归档、解码等），可查看进度、**重试** 或 **取消**，并清除已完成项。

### 隐私与工具

- **设置 → 隐私与安全**：关闭 / 最小化到托盘、启动密码、老板键一键隐藏窗口。
- **设置 → 工具**：指定 Jasna、Transub、Transub Player 路径；左轨工具菜单也可快捷打开这些程序。
- **设置 → 备份**：备份 / 恢复数据库，或导出 / 导入配置与源数据包（不含密码与激活码）。

## 数据

影片索引与配置、筛选库均保存在本机，不上传。

```
影片及配置：<Banas.exe 所在目录>/data/javgt.sqlite
筛选库：    <Banas.exe 所在目录>/data/catalog.banascat
```

备份或迁移时，复制整个 `data` 文件夹即可。

## 授权

首次使用可全功能试用 3 天。试用结束后仍可扫描、浏览和整理本地库；联网补全、批量整理、内容源、下载源与监听等需 Pro。

在 UniFans 购买后等待发放激活码，粘贴到「设置 → 授权」。每个激活码绑定一台电脑，换绑间隔 30 天。可选时长：一年、两年或永久。
